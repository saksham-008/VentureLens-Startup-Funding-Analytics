# 🚀 Startup Growth Intelligence Dashboard

## Project Overview
An end-to-end Business Analyst project analyzing 3,000+ 
Indian startup funding records to identify growth trends, 
investment patterns, and business opportunities.

## Business Questions Answered
1. Which industries attract the most funding?
2. Which cities are India's startup hubs?
3. How has funding grown year over year?
4. What investment types are most common?
5. Which startups received the highest funding?
6. Which months see highest funding activity?
7. Who are the most active investors in India?

## Key Findings
- eCommerce leads with $8bn+ in total funding
- Bengaluru receives 3x more funding than Mumbai
- 2017 was the peak funding year (~$10bn)
- Healthcare & Logistics are underserved sectors
- Seed Funding dominates with 35% of all deals

## Tools Used
- Python (Pandas, Matplotlib, Seaborn)
- Power BI Desktop (DAX measures, 5-page dashboard)
- SQL concepts applied in data filtering

## Dashboard Pages
1. Overview — KPI cards + trend charts
2. Industry Deep Dive — sector analysis
3. Geography — city map + location breakdown
4. Investor Activity — VC and deal analysis
5. Recommendations — business insights
